Why Shastra

Everything you need to build
intelligent agents

🤖

Multi-Agent Orchestration

Create hierarchies of agents that automatically hand off tasks to specialized sub-agents. Build complex workflows with ease.

🧩

Typed Tool System

Define type-safe tools with Zod schema validation. Inputs are automatically validated before execution — no runtime surprises.

🧠

Graph Memory

Persistent user memory backed by a Neo4j knowledge graph. Your agents remember preferences, projects, and relationships across sessions.

🔄

Background Memory Sync

The graph updater runs silently in the background, extracting memories from every conversation turn using a configurable interval.

🛡️

Built-in Guardrails

LLM-powered safety checks on every input and output. Block harmful content, leaked credentials, and policy violations automatically.

📐

Structured Outputs

Force agents to respond in a Zod-validated JSON schema using OpenAI's structured response format. Type-safe agent outputs.

Quick Start

Up and running in minutes

const agent = new Shastra({
  name: 'assistant',

TypeScript 
import { Shastra, Runner } from 'shastra-sdk';
import type { ITool } from 'shastra-sdk';
import { z } from 'zod';

const weatherTool: ITool<{ city: string }, string> = {
  name: 'get_weather',
  description: 'Get the weather for a city',
  inputSchema: z.object({ city: z.string() }),
  executor: async ({ city }) => {
    return `It's sunny in ${city}`;
  }
};

const agent = new Shastra({
  name: 'weather_bot',
  description: 'Weather assistant',
  instructions: 'Use get_weather to answer weather questions.',
  tools: [weatherTool]
});

const runner = new Runner();
await runner.run(agent, 'Weather in Mumbai?');
TypeScript 
import { Shastra, Runner } from 'shastra-sdk';

// Sub-agents
const codeAgent = new Shastra({

index.ts 
import {
  Shastra, Runner,
  initNeo4j, verifyConnection, ensureGraphConstraints,
  startGraphMemory, stopGraphMemory,
  makeMemory
} from 'shastra-sdk';

// ═══════════════════════════════════════════
// 1. INIT  —  connect to Neo4j
// ═══════════════════════════════════════════
initNeo4j({
  uri:      'bolt://localhost:7687',
  username: 'neo4j',
  password: 'your_password'
});

const ok = await verifyConnection();
if (!ok) throw new Error('Cannot reach Neo4j — check your credentials');

// Create uniqueness constraints so MERGE never duplicates nodes.
// Safe to call every startup — it's idempotent.
await ensureGraphConstraints();

// ═══════════════════════════════════════════
// 2. START  —  launch background memory sync
// ═══════════════════════════════════════════
// Every 2 minutes the SDK checks globalContext for new messages,
// extracts entities (preferences, technologies, projects, …),
// and writes them to Neo4j using generated Cypher MERGE queries.
startGraphMemory({
  userId:         'user_123',
  intervalMs:     2 * 60 * 1000,  // 2 minutes
  runImmediately: false,            // wait until first message arrives
  verifyOnStart:  true             // ping DB once before starting timer
});

// ═══════════════════════════════════════════
// 3. USE  —  run your agent
// ═══════════════════════════════════════════
const agent = new Shastra({
  name:         'assistant',
  description:  'A personalized AI assistant with long-term memory',
  instructions: 'You are a helpful assistant. Use the Knowledge Graph
                 Context provided to personalize your responses.'
});

const runner = new Runner();

// Tell the agent something about yourself.
// This message lands in globalContext — the background sync
// will pick it up and write it to Neo4j in the next interval.
await runner.run(agent, 'I love building with TypeScript. I hate writing YAML.');

// On the next run(), the SDK automatically:
//  • Queries Neo4j for context relevant to the user's message
//  • Injects that context into the agent's system prompt
//  • The LLM sees: "- WORKS_WITH: TypeScript [Type: Language]
//                   - DISLIKES: YAML [Category: DevOps]"
const reply = await runner.run(agent, 'What config format should I use?');
console.log(reply);
// → "Since you prefer TypeScript and dislike YAML, consider
//    using TypeScript config files (e.g. vite.config.ts)..."

// Optional: force a memory save right now instead of waiting
// for the next background tick.
const mem = await makeMemory(undefined, 'user_123');
console.log(`Saved ${mem.extracted.entities.length} entities to Neo4j`);

// ═══════════════════════════════════════════
// 4. STOP  —  graceful shutdown
// ═══════════════════════════════════════════
// Drains any in-flight memory sync, then closes the Neo4j driver.
process.on('SIGINT',  async () => { await stopGraphMemory(true); process.exit(0); });
process.on('SIGTERM', async () => { await stopGraphMemory(true); process.exit(0); });

Graph Memory

Persistent knowledge that
grows over time

Shastra maps every conversation into a rich Neo4j knowledge graph. Your agents get contextual memory automatically injected into every query.

Knowledge Graph Schema

User:id
Preference:name, category, type
Technology:name, type
Project:name, description
Topic:name
Person:name

Relationships

User─[LIKES]─▶Preference
User─[DISLIKES]─▶Preference
User─[WORKS_ON]─▶Project
User─[WORKS_WITH]─▶Technology
User─[INTERESTED_IN]─▶Topic
User─[KNOWS]─▶Person
Project─[USES]─▶Technology

Full Walkthrough

Graph Memory — end-to-end in code

How each piece fits together: Neo4j init → background sync → agent run with auto-context injection → manual extraction → shutdown.

01

Initialize Neo4j & create constraints

Call initNeo4j() once at startup. verifyConnection() pings the DB. ensureGraphConstraints() creates uniqueness constraints on each node type so MERGE never duplicates nodes.

import { initNeo4j, verifyConnection, ensureGraphConstraints } from 'shastra-sdk';

initNeo4j({ uri: 'bolt://localhost:7687', username: 'neo4j', password: 'pass' });
const ok = await verifyConnection();    // → true
await ensureGraphConstraints();          // run once — idempotent
02

Start background memory sync

startGraphMemory() launches a setInterval that watches globalContext. Every tick it calls getUpdatedContext() to get only new messages since the last sync, then calls makeMemory(delta, userId) — so the LLM only processes fresh content, not the full history.

import { startGraphMemory, isGraphUpdaterRunning } from 'shastra-sdk';

startGraphMemory({
  userId:         'user_123',
  intervalMs:     120_000,    // how often to check for new messages
  runImmediately: false,       // don't run before the first turn
  verifyOnStart:  true         // ping Neo4j before starting the timer
});

console.log(isGraphUpdaterRunning()); // true
03

Run the agent — context is injected automatically

Once the graph updater is running, isUsingGraphDb() returns true. Every runner.run() call then automatically invokes makeQueryContext(query, userId) and appends the result to the agent's system prompt as "Relevant Knowledge Graph Context". Your instructions don't need to change.

import { Shastra, Runner } from 'shastra-sdk';

const agent = new Shastra({
  name:         'assistant',
  description:  'Personalized AI assistant',
  instructions: 'Help the user based on what you know about them.'
});

const runner = new Runner();

// Turn 1 — user tells the agent something about themselves
await runner.run(agent, 'I love TypeScript and I hate writing YAML.');

// Turn 2 — graph context is automatically retrieved & injected:
// System prompt now includes:
//   Relevant Knowledge Graph Context:
//   - WORKS_WITH: TypeScript [Type: Language]
//   - DISLIKES: YAML [Category: DevOps]
const reply = await runner.run(agent, 'What config format should I use?');
console.log(reply);
// → "Since you dislike YAML, I'd recommend using TypeScript-native
//    configs or JSON — here's how..."
04

Manually save memory with makeMemory()

The background sync calls makeMemory() on a timer. You can also call it on-demand — after an important session, from a webhook, or at logout. Pass undefined to use globalContext, or pass any string or message array for custom context.

import { makeMemory } from 'shastra-sdk';

// Uses globalContext automatically
const result = await makeMemory(undefined, 'user_123');
console.log(result.success);                 // true
console.log(result.extracted.entities);
// [{name:'TypeScript', type:'Technology', relationshipToUser:'WORKS_WITH'},
//  {name:'YAML', type:'Preference_Dislike', relationshipToUser:'DISLIKES'}]
console.log(result.extracted.queries.length); // 4 Cypher MERGE queries executed

// Or from a plain string
const r2 = await makeMemory('I am building an SDK called Shastra.', 'user_123');
// → Project node "Shastra" created in Neo4j

// Check if a node already exists before writing
import { checkNodeExists } from 'shastra-sdk';
const exists = await checkNodeExists('Technology', 'name', 'TypeScript');
console.log(exists); // true
05

Graceful shutdown

stopGraphMemory(true) stops the interval, awaits any in-flight makeMemory() call to finish cleanly, then closes the Neo4j driver. Always call this on process exit — the timer is .unref()'d in Node.js so it won't block exit by itself, but you should still flush pending updates.

import { stopGraphMemory } from 'shastra-sdk';

process.on('SIGINT', async () => {
  // true = also close the Neo4j driver after draining in-flight sync
  await stopGraphMemory(true);
  process.exit(0);
});

process.on('SIGTERM', async () => {
  await stopGraphMemory(true);
  process.exit(0);
});
Safety

Built-in guardrails on
every message

Shastra wraps every runner.run() call with LLM-powered safety checks. Zero configuration required.

🚦

Input Guardrail

User → Agent

Checks every user message before the agent processes it.

  • ✗ Sexual or hacking-related content
  • ✗ Personal identifying information
  • ✗ Malicious system operations
🔒

Output Guardrail

Agent → User

Checks every agent response before returning it to the caller.

  • ✗ Leaked API keys or passwords
  • ✗ Database URLs or credentials
  • ✗ Offensive or political content
⚠️

GuardrailError

Error Class

Violations throw a typed GuardrailError with a detailed reason.

try {
  await runner.run(agent, input);
} catch (e) {
  if (e instanceof GuardrailError) {
    e.message   // "Input rejected"
    e.reason    // "Violates safety policy"
  }
}
